## 🧴 Project 1 — LUMINA

### Luxury Organic Soap E-Commerce Platform

> **The brief:** Build a complete online store for a luxury organic soap brand — full shopping experience, custom orders, payment processing, and backend management.

<table>
  <tr>
    <td><b>Type</b></td>
    <td>Full-Stack E-Commerce Platform</td>
  </tr>
  <tr>
    <td><b>Stack</b></td>
    <td>Next.js 14 · TypeScript · Tailwind CSS · Node.js · Express · MongoDB · Paystack · Flutterwave · Cloudinary · Vercel · Render</td>
  </tr>
  <tr>
    <td><b>Auth</b></td>
    <td>JWT with separate customer & admin secrets</td>
  </tr>
  <tr>
    <td><b>Testing</b></td>
    <td>Vitest + Testing Library (frontend) · Jest + fast-check (backend)</td>
  </tr>
</table>

**What was built:**

- 🛍️ Full storefront — product catalogue, category filtering, pagination, stock management
- 🛒 Persistent cart — works for guests and authenticated users
- 💳 **Dual payment gateway** — Paystack primary, Flutterwave automatic fallback (zero downtime on payment failure)
- 🧼 Custom soap request form — scent, color, size, quantity, special instructions
- 👤 Customer accounts — full order history and transaction tracking
- 🖥️ **Complete admin dashboard** — product CRUD with Cloudinary image uploads, order management, custom request handling, sales stats
- 📧 Automated email notifications to admin on every new order and custom request
- 🔐 Rate limiting on auth routes, HMAC webhook signature verification
- ✅ Full test coverage — unit, integration, and property-based tests
